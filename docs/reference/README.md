# Reference material from v1 / v2

These two files are historical. They describe the **previous** four-surface design language
(Landing gradient · Console tri-tone · Archive paper · Night Ops purple) that v3 deliberately replaced with a
single unified system.

They are kept because the burgundy accent, the Archivo / JetBrains Mono / Courier Prime type pairing and the
shield mark all came from here and all survived into v3.

For the design system that is actually in force, read `docs/design-system.md` and `src/styles/tokens.css`.
